# 无限画布（wzai-design）

玩赚 AI 设计工作台（无限画布）桌面客户端，当前正式版本 v1.0（1.0.0）。

- 安装包：见 [Releases](https://github.com/pazmulroneyv-alt/wzai-design/releases)
- 设置页内置升级入口：检查 Release、下载、SHA-256 校验并拉起安装
- 校验值：每个安装包附 `.sha256` 文件
- 局域网副本：`\\192.168.88.8\wz\无限画布二开\wzai-design-v1.0`

## 支持的安装包

| 系统 | 安装包 |
| --- | --- |
| Windows x64 | `Wanzhuan-AI-Design-Setup-1.0.0-x64.exe` |
| Linux x64 | `Wanzhuan-AI-Design-1.0.0-linux-amd64.deb`、`…-linux-x86_64.AppImage` |
| Linux arm64 | `Wanzhuan-AI-Design-1.0.0-linux-arm64.deb`、`…-linux-arm64.AppImage` |
| macOS Intel | `Wanzhuan-AI-Design-1.0.0-macos-x64.dmg` |
| macOS Apple Silicon | `Wanzhuan-AI-Design-1.0.0-macos-arm64.dmg` |

Linux 为用户级安装：deb 仅放置只读安装源，程序安装到 `~/.local/share/wanzhuan-ai-design/app`，运行不需要 root。
